# خرج‌نگار DIANCO — پروژه آغازین Android Studio

## امکانات فعلی
- رابط Kotlin + Jetpack Compose
- واترمارک نیمه‌شفاف DIANCO در پس‌زمینه صفحه اصلی و قابل استفاده در تمام صفحات از طریق `DiancoWatermark`
- ثبت دستی هزینه‌ها با واحد تومان
- پایگاه داده محلی Room/SQLite
- ثبت اولیه پیامک‌های برداشت بانک تجارت با قالب‌های مشخص‌شده
- ثبت انتقال وجه جدا از هزینه مصرفی
- فهرست تراکنش‌های نیازمند توضیح و امکان افزودن توضیح
- ذخیره نکردن متن کامل پیامک

## باز کردن پروژه
پوشه `KharjNegar` را در Android Studio باز کنید، Gradle Sync را اجرا کنید و سپس از منوی Build، گزینه Build APK(s) را انتخاب کنید.

## محدودیت‌ها و حریم خصوصی
- این پروژه منبع است؛ APK از پیش کامپایل و روی گوشی آزمایش نشده است.
- قالب پیامک فعلاً فقط نمونه‌های محدود بانک تجارت را می‌شناسد؛ قبل از اتکا به آن باید با نمونه‌های واقعیِ بدون اطلاعات محرمانه تست شود.
- شناسایی انتقال بین حساب‌های خود کاربر هنوز پیاده‌سازی نشده؛ فعلاً پیامک‌های انتقال با نوع TRANSFER جدا می‌شوند.
- توضیح صوتی، گزارش‌های پیشرفته، پشتیبان‌گیری امن و رمزگذاری پایگاه داده در این نسخه وجود ندارند.
- برنامه نباید رمز کارت، CVV2 یا رمز یک‌بارمصرف را دریافت یا ذخیره کند.
- دسترسی پیامک به مجوز Android وابسته است و ممکن است بر اساس نسخه سیستم‌عامل و محدودیت‌های توزیع برنامه تغییر کند.
- داده‌ها روی دستگاه نگهداری می‌شوند و به سرور ارسال نمی‌شوند، اما پایگاه داده این نسخه رمزگذاری نشده است؛ برای استفاده با داده‌های حساس باید رمزگذاری اضافه شود.

## واترمارک در صفحات جدید
محتوای هر صفحه را داخل `DiancoWatermark { ... }` قرار دهید تا نام DIANCO به شکل کم‌رنگ در پس‌زمینه آن صفحه نمایش داده شود.
